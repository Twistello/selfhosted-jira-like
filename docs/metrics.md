# Показатели версии 1

Источник — реальные tasks/events/time_entries. День длится 86400000 ms; длительности пока календарные, не рабочие. Значения `null` означают отсутствие достаточных данных, а не ноль.

| Поле API | Формула/источник | Границы |
|---|---|---|
| total_count | Количество выбранных задач | Общий проект исключает корзину |
| completed_count/throughput | Количество задач в done | Без фильтра периода это общий итог, не скорость за неделю |
| planned_points | Сумма story_points baseline выбранного спринта | В проектном агрегате без спринта — 0 |
| completed_points | Сумма points завершённых выбранных задач | Пропущенная оценка считается 0 |
| predictability | Завершённые исходные baseline points / все baseline points × 100 | При нулевом плане null; добавленный scope не повышает показатель |
| lead_time_days | Среднее completed_at − created_at для done | Отрицательные значения ограничены нулём; без завершений null |
| cycle_time_days | Среднее completed_at − первый status_changed.to=in_progress | Без известного начала задача исключена из среднего |
| rework_count | Количество переходов в returned | События, а не число уникальных задач |
| aging | now − created_at для незавершённых | Для закрытого спринта now зафиксирован временем закрытия |
| estimated_minutes | Сумма оценок выбранных задач | Закрытый спринт читает snapshot |
| actual_minutes | Сумма time_entries | Для спринта только записи связанных задач в его окне; закрытие замораживает записи |
| by_status | Количество выбранных задач на статус | Не процент |
| scope_changes | События scope_added/scope_removed с причиной | Carryover отличается от завершения |

Закрытый спринт читает immutable `sprint_closed.data.snapshot` с baseline, задачами и time entries на момент закрытия. Поздние переоценки, возвраты и time entries не меняют его отчёт. Старый спринт без снимка возвращает явную ошибку; старый снимок без времени возвращает `actual_minutes:null`.

`cumulative_flow` пока экспериментален: восстанавливает состояния только на днях известных событий и не моделирует полностью удаления/scope; это не готовый CFD отчёт. Burndown/burnup, velocity по итерациям, planned/completed scope chart, фильтры по периоду/исполнителю, персональные dashboards и PDF пока не реализованы. CSV/JSON экспортирует задачи с проверкой проектного доступа; CSV экранирует формулы.
